 Architecture

End-to-End Pipeline

From raw TMDB API data to classified genres — every step runs on Hadoop MapReduce.

1

TMDB API Ingestion

Fetch 13,711 movies from /movie/popular, top_rated, now_playing, upcoming — deduplicated by ID.

2

Metadata Enrichment

Append keywords, tagline, cast & director via /movie/{id}?append_to_response=keywords,credits.

3

HDFS Upload

Genre-partitioned text files uploaded to hdfs://namenode:9000/movie_data_raw/<Genre>/

4

seqdirectory → SequenceFiles

Mahout MapReduce converts genre text dirs into Hadoop SequenceFile format for vectorization.

5

seq2sparse — TF-IDF Vectors

EnglishAnalyzer (Porter stemmer + stopwords), bigrams (-ng 2), L2 normalization. 221MB vector output.

6

Complementary Naive Bayes

80/20 train/test split. trainnb → testnb MapReduce jobs. Final accuracy: 50.59% on 2,775 test docs.

Movie Genre Classification @ Scale

A Big Data Systems project at IIIT Naya Raipur (Sem 2) demonstrating end-to-end machine learning on a distributed Hadoop/Mahout cluster. The pipeline processes enriched movie metadata — titles, overviews, keywords, cast, and taglines — to classify 13,711 movies across 17 genres using Complementary Naive Bayes with TF-IDF bigram features.
